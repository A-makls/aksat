# أقساطي وديوني

تطبيق ويب بسيط (ملف HTML واحد) لإدارة الأقساط والديون باللغة العربية.

## الميزات
- تسجيل الأقساط والديون وتجميعها حسب الشخص
- تذكيرات ورسائل واتساب
- إيصالات
- تصدير Excel ونسخ احتياطي واسترجاع
- قفل برقم سري (PIN)
- وضع فاتح/داكن

## التشغيل
افتح `index.html` في المتصفح، أو انشره عبر GitHub Pages:
1. Settings ← Pages
2. Source: `Deploy from a branch` ← الفرع `main` ← المجلد `/ (root)`
3. سيظهر الرابط بعد دقيقة تقريبًا.

## ملاحظة
البيانات تُحفظ محليًا في المتصفح (localStorage) ولا تُرسل لأي خادم.
