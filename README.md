# أقساطي وديوني (v1.3)

تطبيق ويب (PWA) عربي لإدارة الأقساط والديون والعملاء والمخزن، يعمل بدون إنترنت ويُثبَّت على الشاشة الرئيسية.

## النشر على GitHub Pages
1. ارفع **كل ملفات هذا المجلد** إلى جذر المستودع (استبدل الملفات القديمة عند السؤال).
2. من المستودع: **Settings ← Pages** ثم اختر الفرع (`main`) والمجلد `/ (root)` واضغط Save.
3. بعد دقيقة يعمل التطبيق على: `https://<اسم-المستخدم>.github.io/<اسم-المستودع>/`
4. لوحة إدارة التفعيل على نفس الرابط مع `admin.html`.

## الملفات
| الملف | الوظيفة |
|---|---|
| `index.html` | التطبيق كاملاً (واجهة + منطق) |
| `r.html` | صفحة عرض الوصل التي يفتحها العميل من رابط واتساب (بيانات الوصل مختصرة داخل الرابط `?d=`) |
| `admin.html` | لوحة إدارة التفعيل (إصدار الرموز، نسخ احتياطي، Google Drive) |
| `license.js` | شاشة التفعيل والتحقق من الرمز |
| `license-config.js` | المفتاح العام + رقم واتساب التفعيل |
| `sw.js` | العمل بدون إنترنت والتحديث |
| `manifest.webmanifest` / `admin.webmanifest` | بيانات التثبيت للتطبيق واللوحة |
| `icon-*.png` | أيقونات التطبيق |
| `CHANGELOG.md` | سجل التغييرات |

## عند كل تحديث
- غيّر رقم `VERSION` في `sw.js` (مثل `aqsati-v3.2`) حتى تسحب الأجهزة الملفات الجديدة.
- حدّث الصفحة بقوة بعد الرفع.

## ملاحظات مهمة
- **مفتاح التفعيل:** بصمة `license-config.js` (تظهر بجانب `key` أسفل شاشة التفعيل) يجب أن تطابق «بصمة مفتاحك» في لوحة الإدارة، وإلا تُرفض كل الرموز. إذا غيّرت المفتاح يحتاج العملاء رموزاً جديدة.
- **النسخ الاحتياطي للوحة:** خذ نسخة من لوحة الإدارة (ملف أو Google Drive) قبل تغيير الجهاز أو مسح بيانات المتصفح.
- **Google Drive:** يعمل من رابط `https` فقط، ويلزم أن يكون `https://<اسم-المستخدم>.github.io` ضمن «Authorized JavaScript origins» لمعرّف العميل.
- **روابط الوصلات:** تُبنى على نفس مسار التطبيق (`.../r.html?d=...`)، فلا تنقل `r.html` من مكانه. صورة المعاينة في `r.html` (وسم `og:image`) تشير إلى `https://a-makls.github.io/aksat/icon-512.png`، عدّلها إذا غيّرت الرابط.
- **التثبيت:** يعمل من رابط `https` فقط (وليس من ملف محلي).
