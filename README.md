# دفتر الأقساط والديون (أقساطي) — الإصدار 1.1

تطبيق ويب يعمل بدون خادم لإدارة الأقساط والديون والعملاء والمخزن والمصروفات والوصولات.
تُحفظ البيانات في المتصفح نفسه (`localStorage`)، ويمكن تثبيته كتطبيق (PWA) والعمل بدون إنترنت.

> **نسخة مسطّحة:** كل الملفات في مكان واحد (بدون مجلدات css/js/icons) لتسهيل الرفع من الجوال. الأسماء كما في الهيكل أدناه لكن بدون المجلد (مثلاً `js/01-core.js` ← `01-core.js`).

## هيكل المشروع

```
index.html              الصفحة الرئيسية (الهيكل + ترتيب تحميل السكربتات)
manifest.webmanifest    بيانات التثبيت كتطبيق
sw.js                   Service Worker للعمل بدون إنترنت
css/style.css           كل الأنماط (ليلي/نهاري، شاشات كبيرة، شاشة البداية، الطباعة)
icons/                  أيقونات التطبيق (180 / 192 / 512)
js/
  logo.js               شعار الواجهة (SVG)
  01-core.js            الحالة والتخزين والدوال المساعدة والحسابات
  02-ui.js              النماذج والحوارات والإشعارات وإجراءات الإضافة
  03-pages.js           صفحات العرض (المتأخرات، التسديدات، المخزن، العملاء، تفاصيل القسط والدين)
  04-receipts.js        توليد الوصولات (Canvas) ومشاركتها
  05-payments.js        الاتصال، تسديد الأقساط، تنسيق حقول المبالغ
  06-home.js            الإعلانات، الصفحة الرئيسية، الإعدادات، البحث
  07-installments.js    حساب التأخير، نموذج القسط، التنقل السريع
  08-settings.js        المظهر، الإعدادات، من نحن
  09-debts-form.js      نموذج إضافة الدين
  10-backup.js          صفحة النسخ الاحتياطي والتصدير
  11-lists.js           بطاقات الأقساط وتفاصيل العميل وتسديد المجموعات
  12-backup-io.js       تحويل Excel واستيراد/استعادة النسخ
  13-search.js          بحث الترويسة
  14-pin.js             رمز الحماية
  15-filters.js         تصفية البطاقات (نشطة/متأخرة/مكتملة)
  16-tiles.js           أيقونات وأقسام الإعدادات
  17-i18n.js            الترجمة (عربي/English)
  18-backup-text.js     النسخ النصي ومسح البيانات
  19-app.js             العرض الرئيسي والتنقل وتشغيل التطبيق
  pwa.js                تسجيل الـ Service Worker
```

> ملفات `js/` سكربتات كلاسيكية تتشارك النطاق العام (لأن الواجهة تستدعي الدوال عبر `onclick`).
> **الترتيب في `index.html` مهم** ولا يجوز تغييره.

## التشغيل

- **سريعاً:** افتح `index.html` مباشرة في المتصفح (كل شيء يعمل عدا التثبيت والعمل بدون إنترنت).
- **محلياً مع PWA:** `python3 -m http.server 8080` داخل المجلد ثم افتح `http://localhost:8080`.

## النشر على GitHub Pages

1. أنشئ مستودعاً جديداً على GitHub (مثلاً `aqsati`).
2. ارفع **محتويات** هذا المجلد إلى جذر المستودع (يجب أن يكون `index.html` في الجذر، وليس داخل مجلد فرعي).
3. من **Settings ← Pages** اختر: Source = *Deploy from a branch*، Branch = `main`، Folder = `/ (root)`، ثم Save.
4. بعد دقيقة يصبح التطبيق على `https://USERNAME.github.io/aqsati/`.
5. افتح الرابط من Safari/Chrome ثم «إضافة إلى الشاشة الرئيسية».

ملاحظات:
- المسارات كلها نسبية فتعمل تحت `/aqsati/` بلا تعديل.
- **بيانات المتصفح مرتبطة بالنطاق:** الرابط الجديد له تخزين مستقل، فانقل بياناتك القديمة عبر النسخ النصي (نسخ ثم لصق ثم استعادة).
- عند نشر تحديث: ارفع رقم الإصدار في `js/11-lists.js` (`APP_VER`) وفي `sw.js` (`VERSION`) ليحمّل المستخدمون الملفات الجديدة.
- لم أضف ملف ترخيص (LICENSE)؛ اختر ما يناسبك عند إنشاء المستودع.

## ملاحظات وقيود معروفة (لم تُغيَّر عمداً)

- **الرمز السري (PIN)** قفل على الواجهة فقط؛ البيانات نفسها غير مشفّرة في `localStorage`.
- **البيانات مرتبطة بمتصفح واحد وجهاز واحد** (لا مزامنة). خذ نسخة احتياطية دورياً، ومسح بيانات الموقع يحذفها.
- **حساب التأخير** يُبنى على تاريخ آخر دفعة (أي دفعة تُعيد احتساب الموعد). هذا قرار تصميم؛ راجعه إن أردت جدول أقساط ثابتاً.
- **الخط Cairo** يُحمَّل من Google Fonts (يُخزَّن بعد أول تحميل). لعمل كامل بلا إنترنت من أول مرة استضف الخط محلياً.
- **مكتبة Excel:** لعمل كامل بلا إنترنت ضع `xlsx.full.min.js` (SheetJS 0.18.5) في `vendor/`.
- **الأيقونات** 192/512 مولّدة بتكبير أيقونتك الأصلية (180px)؛ استبدلها بنسخ عالية الدقة.
- **قسم «من نحن»** يحتوي روابط وأرقام المطوّر الأصلي (فيسبوك/واتساب)؛ عدّلها في `js/08-settings.js` إن لزم.
- **الترجمة الإنجليزية** تعمل باستبدال نصوص عربية؛ قد تتأثر بيانات تحتوي كلمات مثل «قسط».

## الاختبار

اختُبر على Chromium (Playwright): مقارنة 21 عرضاً بين الأصل والجديد (متطابقة عدا النسخة النصية التي عُدّلت عمداً)، ومقارنة بصرية لـ16 لقطة
(نهاري/ليلي) بفارق 0%، واختبارات للإصلاحات أعلاه، ومسارات كاملة (إضافة/تعديل/حذف قسط ودين، تسديد، وصولات،
PIN، لغة، مظهر)، وعمل Service Worker بدون إنترنت.
**ملاحظة:** مكتبة SheetJS الحقيقية لم تُختبر (لا شبكة في بيئة الاختبار)؛ اختُبر منطق التصدير/الاستعادة ومسار التنزيل
بمكتبة بديلة. جرّب تصدير Excel واستعادته مرة على جهازك.
