# درع (Shield)

تطبيق ويب عربي يساعد من يتعرض للابتزاز بالصور على حماية صوره وحفظ الأدلة ومعرفة الخطوات الصحيحة.

**الرابط:** https://a-makls.github.io/Shield/

## المميزات

- توجيه لخدمات الحماية الرسمية: [StopNCII](https://stopncii.org) للبالغين، و[Take It Down](https://takeitdown.ncmec.org) لمن هم دون 18 سنة
- حفظ لقطات الأدلة داخل المتصفح على جهاز المستخدم فقط، دون إرسالها لأي خادم
- دليل بخطوات واضحة لمن يتعرض للتهديد
- واجهة بالعربية والإنجليزية، ووضع نهاري وليلي
- قابل للتثبيت على الجوال كتطبيق مستقل، مع زر مشاركة الرابط
- متوافق مع مختلف أحجام الشاشات

## ملفات المشروع

| الملف | الوظيفة |
|---|---|
| `index.html` | التطبيق كاملاً |
| `manifest.webmanifest` | بيانات التثبيت كتطبيق |
| `sw.js` | خدمة العمل في الخلفية للتثبيت |
| `icon.svg`، `favicon-32.png` | أيقونة المتصفح |
| `apple-touch-icon.png` | أيقونة الشاشة الرئيسية في آيفون |
| `icon-192.png`، `icon-512.png` | أيقونات التثبيت |

## النشر على GitHub Pages

1. ارفع كل الملفات في أول المستودع (بدون مجلدات).
2. من Settings ثم Pages اختر Deploy from a branch، والفرع `main`، والمجلد `/ (root)`.
3. بعد دقيقة إلى ثلاث يظهر الرابط.

## التحديث

استبدل الملفات المتغيرة من Add file ثم Upload files. وإذا ظهرت النسخة القديمة بعد الرفع، أغلق التبويب وافتح الرابط من جديد.

## ملاحظة

التطبيق لا يحجب الصور بنفسه، بل يوجّه المستخدم للخدمات الرسمية التي تتعاون مع المنصات.
